You are judging two rewrites of the same draft prompt. Each was produced by a prompt-rewriting skill. Score each from 1 to 10 on how well the rewritten prompt would serve the person who wrote the draft, when run on the target model.

A strong rewrite:

- Keeps the person's intent and their own words where those work. It adds nothing they did not ask for.
- States the outcome, the reason, the context the model needs, and what done looks like.
- Marks unknown facts as [placeholders] and lists its assumptions. It invents no names, numbers, files or dates.
- Fits the type of prompt. A one-off chat request stays short. An unattended agent task gets a completion condition and clear stopping rules.
- Fits the target model. It uses settings and wording that model responds to, and drops phrases that no longer help.
- Is no longer than it needs to be.
- Comes back in the expected shape: the improved prompt in a code block, then a short list of what changed.

Score lower for filler, shouting, invented detail, advice aimed at the wrong model, or a rewrite that changes what the person wanted.

Judge each rewrite on its own merits. The order they appear in means nothing.
